El proyecto para una Gestión de Seguros es una plataforma web desarrollada para automatizar y optimizar los procesos de administración de seguros de vida y salud. El sistema incluye funcionalidades como:
•	Inicio de sesión diferenciado por roles (administrador, agente, cliente).
•	Gestión de usuarios y pólizas, con opciones para crear, editar y eliminar registros.
•	Contratación de seguros mediante un flujo de trabajo que incluye carga de documentos y firma electrónica.
•	Solicitud y aprobación de reembolsos con seguimiento de estados (pendiente, aprobado, rechazado).
•	Despliegue en AWS para asegurar accesibilidad y rendimiento.
El proyecto fue desarrollado utilizando tecnologías como Flask (backend), MySQL (base de datos), y herramientas como VS Code, y Git Bash.
